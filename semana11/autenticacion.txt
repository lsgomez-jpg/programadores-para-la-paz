El login es el proceso que permite identificar a un usuario antes de ingresar a una aplicación. Gracias a la autenticación, solo las personas autorizadas pueden acceder a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten modificar datos importantes. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
